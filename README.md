### 프로젝트 개요

기존 세차장 이용시 발생하는 긴 대기시간의 불편함 해소를 위함<br/>
사용자 편의 향상을 위해 위치 기반 세차장 조건 검색, 즐겨찾기 및 예약 서비스 구현

#### 수행기간 **2024.12.13 - 2025.02.17**

### 팀원 역할

#### | 김보라

공통 프론트엔드, 예약 프로세스(C.R.U), 세차장 상세정보(R), 게시판(R.U) 구현

#### | 하석준

카카오 API 활용 -> 세차장 탐색 및 즐겨찾기, 리뷰 (C.R.U.D), FAQ & 관리자(C.R.U.D) 구현

#### | 김현서(조장)

기획 총괄, DB 구축 & 관리, tiles 관리, 고객 등급혜택(R) 구현, 최종 발표 산출물 작성

#### | 이현진

콘텐츠 기획, 스토리보드 및 회의록 작성, 회사소개

## 프로젝트 회고

#### 김보라

프로젝트에서 맡은 개발 업무 중 특히 에약프로세스 단계별 작업을 통해 선택된 값의 전달에 대해 심층적으로 알 수 있었습니다. 세차장 상세화면에 스태프 정보 조회시 일대다, 다대일 관계에 대해 정확히 알게 되었으며, 공지사항의 이전글, 다음글 조회 구션시엔 기존코드를 활용하는 법을 익혔습니다. 공통 프론트를 적용하면서는 고객, 어드민의 타일즈 레이아웃을 분리해보았는데 개인 역량 강화에 많은 도움이 되었습니다. 마지막으로 타인의 코드를 분석하며 프론트를 적용하면서 정확하게 알수 없었던 기능구현에 대해서도 알게 되어 참 유익한 시간이였습니다.

#### 하석준

이번 프로젝트를 통해 Spring 기반 웹 개발을 실무에 가깝게 경험할 수 있었습니다. 특히, 회원관리, 세차장 탐색 기능, FAQ 기능 등을 구현하며 API연동, JAVA, JSP + JavaScript활용 등의 기술을 심화 학습할 수 있었습니다. 또한, 에러 디버깅과 기능 개선 과정을 통해 문제 해결 능력을 키울 수 있었습니다. 앞으로는 더 효율적인 코드 구조와 유지보수성을 고려한 개발을 목표로, 지속적으로 성장해 나가고 싶습니다.

#### 김현서

이번 프로젝트를 통해 다양한 분야의 팀원들과 협업하며 효율적인 업무 분담과 일정관리의 중요성을 깨달았습니다. 프로젝트 기획부터 개발까지 주도하며 웹 개발의 흐름과 구조를 깊이 이해하게 되었고, 향후 더 큰 규모의 프로젝트에서도 유연하게 대응할 수 있는 자심감을 얻었습니다. 또한 팀원들과 문제를 해결해 나가며 커뮤니케이션 능력과 리더십을 발전시킬 수 있었던 소중한 경험이었습니다. 끝으로, 열심히 따라와 준 팀원들, 유익한 강의를 제공해 주신 강사님과 멀티캠퍼스에 감사드립니다.

### 이현진

이전 프로젝트 코드를 분석하며 개발을 진행하면서 구조와 유지보수의 중요성을 배웠으며, 재사용성과 확장성을 고려한 설계 방식이 인상적이였습니다. 뛰어난조원들의 실력에서 많은 것을 배웠고, 이를 따라가는 것이 쉽지는 않았지만 프로젝트에서 맡은 역할을 최선을 다해 수행하고자 했습니다. 또한, 가독성을 높이기 위해 명확한 변수명과 함수명을 사용하는 것이 중요하다는 점을 깨달았습니다. 앞으로는 코드의 효율성과 가독성을 함께 고려하여 더욱 발전된 방식으로 작성해야겠다고 느꼈습니다.
